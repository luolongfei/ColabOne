# ColabOne

A desktop client for remote Google Colab GPUs organized around a 4-stage navigation flow (`Devices → Public API → ComfyUI → Settings`). Start and manage one or more GPUs, monitor real-time billing endurance and hardware telemetry, select and load a single GGUF LLM on the remote machine (`llama.cpp` on loopback `8081`) via the slide-over model drawer inside `Public API`, expose authenticated OpenAI-compatible text endpoints via Cloudflared (`Public API`), run remote ComfyUI workflows and an authenticated Native Canvas (`ComfyUI`), persist assets to `My Drive / ColabOne_Drive` (using Colab native DriveFS by default, or permanent zero-prompt headless `rclone` auto-mount after accepting the free Google Cloud Terms of Service once), and selectively release instances.

- **Real-time billing endurance & resource telemetry (`Devices` & Top Bar)**: both the persistent top bar and the overview card show live billing status (active vs. idle), hourly CU burn rate (`CU/hr`), remaining CU balance, and human-friendly estimated remaining runtime (days & hours). Once connected, ColabOne real-time hardware charts (`ResourceMonitor.vue` backed by `ColabOneResourceSampler` in `server/telemetry.py` on `/api/v1/status`) visualize remote GPU utilization & VRAM, RAM (`/proc/meminfo`), disk capacity & `/proc/diskstats` I/O throughput, CPU (`/proc/stat`), and a 60-sample rolling `history` in either grid or 4-row stacked views.
- **Unified idle auto-release protection**: replaces single-launch CU budgets (`max_cu`) with a single configurable idle auto-release countdown defaulting to **30 minutes** (`15m`, `30m`, `45m`, `1h`, `2h`), adjustable directly from the overview dropdown or `Settings`, automatically paused during active downloads, VRAM loads, external API inference, or ComfyUI queue/canvas activity, and reset on trusted user interaction.
- **Public OpenAI Gateway (`Public API`) & Integrated GGUF Model Picker Drawer**: built-in desktop chat/image/video interactive views and `stable-diffusion.cpp` (`Z-Image Turbo`, `Wan2.2 5B`) fixed creative recipes have been removed, and GGUF model selection lives directly inside `Public API` as a right-side slide-over drawer (`Select Model` / `Switch Model`). The drawer focuses purely on single-model GGUF LLM selection across two tabs (**My Models** and **Community**), with inline remote download, disk capacity & VRAM fit badges, pre-seeded editable common Hugging Face repositories (`huihui-ai/Huihui-Qwen3.8-Flash-Next-abliterated-v2-GGUF`, `huihui-ai/Huihui-DeepSeek-V4.1-Flash-1017-abliterated-GGUF`, `JonathanColetti/Qwen3.8-27B-Uncensored`), 16/32-thread parallel downloads, inline `8K`–`64K` context length and temperature controls, and one-click `Download & Load` into remote `llama-server` (`127.0.0.1:8081`). `Public API` exposes authenticated OpenAI-compatible `/v1/models`, `/v1/chat/completions`, `/v1/responses` (with function/custom tools & SSE streaming), and `/v1/responses/compact` (Codex context compaction) on remote loopback `7861` exclusively via a fixed-domain Named Cloudflared tunnel.
- **Standalone `ComfyUI` workspace (dual-layer Mode 3: `Workflow Studio` + `Native Canvas`)**: powered by remote-only ComfyUI `v0.46.0` on loopback `8188`.
  - **Workflow Studio (Phase 1 foundation)**: import ComfyUI API-format JSON workflows, auto-generate typed parameter forms, upload input media, run cancellable remote queue executions, browse a SHA-256 verified output gallery with native export dialogs, sync `/workflows/**` and `/comfyui-outputs/**` to `ColabOne_Drive`, and manage remote model/workflow packs via extensible `catalog/comfyui.json`.
  - **Native Canvas**: authenticated HTTP + WebSocket reverse proxy on `127.0.0.1:8189` (random token exchanged for a scoped `HttpOnly` cookie) behind a fixed-domain Named Cloudflared tunnel, openable in a dedicated desktop window or the system browser.
  - **Strict VRAM mutual exclusion**: `llama-server` (`8081`) and `ComfyUI` (`8188`) never occupy GPU VRAM at the same time; switching unloads the active engine while retaining cached weights. Active ComfyUI queues and canvas requests pause the 30-minute idle auto-release countdown.
- **Multi-instance & region visibility**: active and listed GPU instances automatically resolve their country/region (via GCP zone/endpoint and VM metadata/geo fallback) and display crisp built-in vector SVG flags in the topbar and device views.

Targets macOS Apple Silicon and Windows x64. The desktop does not download weights or run inference or workflows locally. Agent and local MCP execution are deferred.

See [README.md](README.md) for setup/build instructions, [architecture](docs/architecture.md), [API](docs/api.md), [NOTICE](NOTICE), and [upstream provenance](third_party/SOURCES.md). Sign in with Google once to start GPUs directly—Drive persistence defaults to Colab native DriveFS (one browser Allow click per new VM) and upgrades to permanent zero-prompt headless `rclone` (`drive.file`) auto-mounting once you accept the free Google Cloud Terms of Service (no credit card, Tailscale, API key, or OAuth JSON required).
